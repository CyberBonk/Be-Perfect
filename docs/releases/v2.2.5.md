# Timer Be Perfect v2.2.5+6

Polished release focused on clearer event status and a more compact timer
surface, while preserving the controller/participant synchronization model.

## Changes since v2.2.0+5

- System feed entries now use concise summaries for timer adjustments, round
  transitions, pauses, resumes, skips, and completions.
- Round transitions use a clear **Next round** state in the timer.
- The timer card gives time remaining a stronger visual focus and keeps round
  progress compact.
- Widget tests cover system-event summaries and cooldown presentation.
- Version metadata advanced to `2.2.5+6`.

## Verification

- `flutter analyze` passed with no issues.
- `flutter test` passed.
- Firebase Functions TypeScript lint passed.
- Release APKs and the App Bundle were built with obfuscation and external
  symbol output.
- SHA-256 values for the four artifacts are recorded in
  [`v2.2.5-SHA256SUMS.txt`](v2.2.5-SHA256SUMS.txt).

## Build

```powershell
flutter build apk --release --split-per-abi `
  --obfuscate --split-debug-info=build/symbols
flutter build appbundle --release `
  --obfuscate --split-debug-info=build/symbols
```
