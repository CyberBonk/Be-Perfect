# Timer Be Perfect v2.1.0+4

First verified Android delivery milestone.

## Highlights

- Multi-room QR/PIN joining with controller and participant roles.
- Synchronized server-clock schedules with local countdown rendering.
- Offline continuation from the last confirmed schedule.
- Persistent round alarms and ongoing Android timer notification.
- English/Arabic localization and church-specific notice wording.
- Firestore fallback path for the Firebase base plan, with Cloud Functions as
  an optional Blaze-plan enhancement.

## Delivery evidence

- Three obfuscated split-ABI APKs.
- One obfuscated App Bundle.
- External symbol files retained for crash decoding.
- SHA-256 checksums included in the Desktop delivery package.
- 36 Flutter tests passed.
- `flutter analyze` passed with no issues.

## Build

```powershell
flutter build apk --release --split-per-abi `
  --obfuscate --split-debug-info=build/symbols
flutter build appbundle --release `
  --obfuscate --split-debug-info=build/symbols
```
