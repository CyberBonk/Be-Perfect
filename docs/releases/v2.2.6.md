# Timer Be Perfect v2.2.6

Targeted release delivering bulletproof notification sound, automatic volume stream maximization, Huawei EMUI ringer protection, and sound readiness UI indicators.

## Changes since v2.2.5

- **Huawei EMUI Ringer Protection**: Prevented device fallback to vibration mode upon room entry by prioritizing volume elevation before ringer mode adjustments and checking current mode.
- **Resilient Volume Maximization**: Wrapped individual audio streams (`ALARM`, `NOTIFICATION`, `MUSIC`, `RING`) in isolated handlers so security restrictions on one stream do not block maximizing the others.
- **Audible Readiness Detection**: Sound readiness now inspects both `RingerMode.NORMAL` and actual stream volume levels (> 15%) to prevent silent conditions when notification volume is muted.
- **1-Tap Max Volume Action**: Added **Max Volume** quick actions on the participant timer banner and settings page to immediately boost volume to 100%.
- **Notification Channel Reset (`_v4`)**: Upgraded announcement channels to `be_perfect_announcements_v4` with `Importance.max` and custom alarm audio to clear stale OEM channel caches.
- **Do Not Disturb (DND) Access Setting**: Added a direct system shortcut in Settings for devices that require notification policy access to automate sound mode switching.

## Verification

- `flutter analyze` passed with no issues.
- `flutter test` passed all unit and widget tests.
- Release APKs and the App Bundle were built with obfuscation and external symbol output.
