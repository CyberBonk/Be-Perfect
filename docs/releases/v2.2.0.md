# Timer Be Perfect v2.2.0+5

Current development release line after the first verified delivery.

## Changes since v2.1.0+4

- Controllers now use the same shared active-run alarm scheduling path as
  participants.
- A schedule key prevents duplicate alarm scheduling during repeated run
  updates.
- English/Arabic locale changes use a 500 ms app-level fade transition.
- Release metadata advanced to version `2.2.0+5`.
- Release APKs were rebuilt with split ABIs, obfuscation, external symbols,
  resource shrinking, and minimized output.

## Verification

The recorded 2.2.0+5 APK and App Bundle rebuilds are verified. The current
App Bundle is 62.2 MB. SHA-256 values for the four artifacts are recorded in
[`v2.2.0-SHA256SUMS.txt`](v2.2.0-SHA256SUMS.txt).

## Build

```powershell
flutter build apk --release --split-per-abi `
  --obfuscate --split-debug-info=build/symbols
flutter build appbundle --release `
  --obfuscate --split-debug-info=build/symbols
```
